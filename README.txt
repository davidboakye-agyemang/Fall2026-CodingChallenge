To run my website, Goldfish
1. In one terminal: cd backend && npm install && node server.js (runs on http://localhost:5001) 
2. In another terminal: cd frontend && npm install && npm run dev (runs on http://localhost:5173) 
3. Open http://localhost:5173 in your browser. Note (the backend runs on port 5001 instead of 5000 to avoid a conflict with my macOS AirPlay Receiver.)
